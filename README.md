
# 🧠 Personality Prediction – Machine Learning Classification

## 📌 Project Overview

This project predicts a person’s personality type based on behavioral and questionnaire data using Machine Learning classification algorithms.
The model analyzes user responses and classifies them into personality categories such as **Introvert, Extrovert, Ambivert**

The goal is to demonstrate:

* Data preprocessing
* Exploratory Data Analysis
* Feature engineering
* Model building & evaluation
* Deployment using Streamlit

---

## 📂 Dataset

* Synthetic / questionnaire-based personality dataset
* Contains psychological trait scores and behavior indicators
* Target variable: **Personality Type**
